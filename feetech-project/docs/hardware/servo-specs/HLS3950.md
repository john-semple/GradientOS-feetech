# HLS3950 Servo Spec

## Identification

- **Manufacturer:** Feetech (FeiTe)
- **Model:** HLS3950M
- **Product code:** HL-3950-C001
- **Family:** HLS series (FT-SCS protocol — same frame format as STS3215)
- **Protocol:** FT-SCS (confirmed from Feetech wiki). See [protocols/feetech-hls.md](../protocols/feetech-hls.md)

## Electrical

| Parameter | Value | Notes |
|-----------|-------|-------|
| Rated voltage | 12V | Confirmed: 12.0V read from register 0x3E |
| Stall current | TBD | To be measured on bench |
| Idle current | ~1.66 A | First read after PING (may be settling; subsequent reads showed lower) |
| Communication | TTL single-wire half-duplex (3-pin) | Same physical layer as STS3215, confirmed working |
| Baud rate | 1 Mbps (default) | Configurable 38400–1 Mbps via register 0x06 |
| Encoder | 12-bit magnetic (0–4095) | Little-endian byte order (END=0) |
| Firmware | 3.43 | Confirmed from register 0x00/0x01 |
| Servo version | 10.18 | From registers 0x03/0x04 |
| Angle limits | 1024–3071 (factory) | EEPROM restricted ~±90° around centre 2048. NOT unrestricted 0-4095 like STS3215 |

## URT-1 connection

- **Channel:** SCS/TTL (3-pin) — same port as STS3215
- User confirmed: "definitely the same single wire setup and should work running through the URT-1"
- The HLS3950 uses the same FT-SCS protocol over the same TTL physical layer

## Pinout

TTL 3-pin (V+, GND, Signal) — same as STS3215.

## Register map summary

The HLS3950 shares the same FT-SCS frame format and instruction set as the STS3215, but the register map has important differences:

| Register | STS3215 meaning | HLS3950 meaning |
|----------|----------------|-----------------|
| 0x07 | Reserved | Sub ID (secondary write-only ID) |
| 0x21 mode 2 | PWM open-loop | Constant current mode |
| 0x22 | Holding torque | Current loop Kp |
| 0x23 | Protection time | Current loop Ki |
| 0x28 | Torque switch (0/1/2/128) | Torque switch (0/1/2 only — no 128 calibrate) |
| 0x2C | PWM open-loop speed | Target current |
| 0x42 | Not present | Moving flag (BIT0=moving, BIT1=reached) |
| 0x43 | Not present | Target position readback |

Full register map: [protocols/feetech-hls.md](../protocols/feetech-hls.md)

## Calibration

Use the `0x0B` instruction (CALIBRATE_MIDDLE) only. Do NOT use the STS3215's torque-switch shortcut (writing 128 to register 0x28) — the HLS3950 ignores it.

## Key differences from STS3215

1. **Register 0x2C is "Target Current"** (not PWM speed) — **writing 0 to 0x2C disables the motor.** The SYNC_WRITE layout is different: HLS starts at 0x2A with 6 bytes (Pos + Current + Speed), STS starts at 0x29 with 7 bytes (Accel + Pos + Time + Speed). See [protocols/feetech-hls.md](../protocols/feetech-hls.md).
2. **EEPROM angle limits are factory-restricted (1024–3071)** — not unrestricted 0–4095 like STS3215. Commands outside limits are silently clamped.
3. **Operating mode 2 is "constant current"** (not PWM) — enables torque control
4. **No torque-switch calibration** — 0x28 only accepts 0/1/2, not 128. Use 0x0B instruction only.
5. **Moving flag (0x42)** and **target position readback (0x43)** are available — bonus feedback not on STS. Moving flag = 0x03 during motion, 0x00 when settled.
6. **Status bits** differ: bit 1 = magnetic encoder (not angle limit), bit 3 = current (not range), bit 5 = load (not overload)

## Backend implementation

The HLS3950 backend lives at `src/gradient_os/arm_controller/backends/hls3950/`:
- `HLS3950Backend(ActuatorBackend)` — driver class
- Registered as `"hls3950"` in the backend registry
- `supports_profiled_segments = True` — same internal trapezoidal profiler as STS3215
