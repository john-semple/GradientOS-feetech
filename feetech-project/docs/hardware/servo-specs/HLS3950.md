## Key unknowns

The HLS3950 is the biggest unknown in the project. Unlike the STS3215 (well-documented SCS family), the HLS series is newer and less documented in the community. The following must be resolved in Phase 2 before any HLS3950 code can be written:

- [ ] **Protocol family** — Is it a variant of SCS? A new protocol entirely? Does it share the same frame format?
- [ ] **Physical interface** — TTL single-wire (3-pin) or RS485 (4-pin) or something else?
- [ ] **URT-1 compatibility** — Can the URT-1 drive it, or does it need a different adapter?
- [ ] **Register map** — What registers exist for position, speed, torque, feedback?
- [ ] **Baud rate** — Default and configurable range
- [ ] **Community libraries** — Does any Python library exist for the HLS series?
- [ ] **Feetech software** — The Feetech host computer software ("FD software") may support HLS servos and could reveal the protocol
