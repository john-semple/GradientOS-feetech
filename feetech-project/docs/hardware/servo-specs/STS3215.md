# STS3215 Servo Spec

## Identification

- **Manufacturer:** Feetech (FeiTe)
- **Model:** STS3215
- **Family:** STS/SCS series (serial bus servos, TTL single-wire half-duplex)
- **Protocol:** SCS/TTL — uses the SCS protocol family (see [protocols/feetech-sts-scs.md](../protocols/feetech-sts-scs.md))

## Electrical

| Parameter | Value | Notes |
|-----------|-------|-------|
| Rated voltage | 12V | User confirms 12V labeled for speed/stall characteristics. **Verify with multimeter before first power-on.** Some variants in the wild are rated 6-8V. |
| Stall current | ~2.5A (at 12V) | To be confirmed from datasheet or bench measurement in Phase 2 |
| Idle current | TBD | Measure during Phase 2 |
| Communication | TTL single-wire half-duplex | 3-pin connector (V+, GND, Signal) |
| Baud rate | ~115200 (typical for SCS family) | To be confirmed |

## URT-1 connection

- **Channel:** SCS/TTL (Channel B, 3-pin 5264-3AW connector)
- **NOT the SMS/RS485 channel** (that's 4-pin, for SMS series servos)
- Power comes from the URT-1's servo-power terminal (fed by bench PSU at 12V)

## Pinout

3-pin connector (SCS/TTL):

| Pin | Function |
|-----|----------|
| 1 | V+ (servo power, 12V) |
| 2 | GND |
| 3 | Signal (half-duplex TTL serial) |

> Verify pin order against the Feetech manual or servo label before connecting.

## Community libraries

- `scservo` / STServo Python libraries exist for the SCS/STS family
- These use a half-duplex single-wire protocol over a serial port
- The URT-1 handles the half-duplex direction switching in hardware (auto-routing), so the library can treat it as a normal serial port
